About

The short version.

I'm the kind of engineer who builds complete AI systems end-to-end. My capstone project CHITTI is a fully autonomous AI voice assistant — I integrated the OpenAI GPT-4o mini API, Sarvam AI's speech-to-text engine, Piper TTS, and a custom-trained wake word model into a single orchestrated pipeline that listens, thinks, and speaks back naturally.

Beyond AI, I've deployed deep learning models as web applications, built IoT automation systems, and designed real-time telemetry workflows. I'm most excited when I'm troubleshooting complex integrations, connecting APIs that weren't designed to talk to each other, and turning messy technical challenges into clean, working solutions.
